# Anjali S Prabhu – Portfolio

React + Vite + Tailwind v4 + GSAP + Lenis.

## Run
```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

## Edit your content
Everything personal lives in **`src/data.js`** (name, links, bio, projects, skills, education / certifications).

- Profile photo: put a square image at `public/profile.jpg` (an "AP" monogram shows until then).
- Resume: replace `public/Anjali_S_Prabhu_Resume.pdf`.
- Project links: set `link` on a project in `src/data.js` to show a "View Project" button.

## Deploy
Push to GitHub and import the repo on Vercel or Netlify (build command `npm run build`, output `dist`).
